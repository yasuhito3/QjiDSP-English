# QjiDSP Quick Start

## — Downloaded QjiDSP? Start Here. —

Thank you for downloading QjiDSP.

QjiDSP is a Linux music player with optional sound-field processing based on CamillaDSP.

The goal is not simply to change the sound, but to explore the **space in which the music seems to exist**.

You do not need to understand all of its features to get started.

**Just listen to one song first.**

## 1. Start QjiDSP

After installation, start QjiDSP from the desktop icon "Qji奏在" or from its directory:

```bash
cd ~/qji
python3 qji.py
```

## 2. Select your DAC

QjiDSP detects available audio output devices.
Select the USB DAC or other audio output you normally use.

QjiDSP is designed around a Linux Audio environment using ALSA.

## 3. Select a DSP mode

When a Loopback output is selected, QjiDSP offers six DSP modes:

- **v1 — Rich Hall (Static)**
- **v2 — Rich Hall (Dynamic)**
- **v3 — Natural Material (Static)**
- **v4 — Natural Material (Dynamic)**
- **v5 — Harmonic Mode**
- **v6 — Harmonic Mode (Headphones)**

For a first experiment:

**Speakers → v5**  
**Headphones → v6**

## 4. Listen to one song

Select some music and start playback.

For the first listen, leave the settings alone and simply enjoy one song.

Then listen to the same song again.

Instead of asking only,

> “Did the sound change?”

try asking:

> **“Does the space around the music feel different?”**

That is one of the ideas behind QjiDSP.

## 5. Please try Bypass, too

QjiDSP also provides:

**Bypass (no audio processing / reference)**

Bypass lets you compare the processed sound with the basic playback sound.

It is especially worth trying if you prefer a source-faithful or traditional hi-fi approach.

During playback, press **[f]** for the audio preset menu and select `Bypass`.
The change is applied from the next track.

After listening in Bypass, return to your favorite DSP preset and compare again.

There is no need to decide which one is “correct.”

**Simply find the sound you prefer.**

## 6. Explore when you feel like it

QjiDSP includes many additional sound modes and features, including:

- Musikverein
- Piano
- Chamber
- Vocal
- Jazz
- Calm
- Deep
- Spatial
- Vinyl Emotion
- Sonia Intelligence
- Air Particle Layer
- Musikverein Room Effects
- Qobuz / SoundCloud / YouTube Music
- AirPlay / UPnP-DLNA
- Internet Radio
- Gapless Playback
- Upsampling

But you do not need to learn everything at once.

**Start with one song.**

Then:

**Listen → Compare → Find what you like.**

That is the simplest way to discover QjiDSP.

### About QjiDSP

QjiDSP does not claim that DSP-processed sound is the only correct way to listen.

You may prefer the unprocessed sound.
You may prefer a wider or more immersive sound field.

**Both are valid ways to enjoy QjiDSP.**

Find the QjiDSP that sounds right to **your ears**.

Welcome to QjiDSP.
