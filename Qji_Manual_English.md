## 1. What is Qji?

**Qji (奏在)** is a high-fidelity music player for Linux. It's more than a simple player — it's a complete listening system built around:

- A serious audio pipeline combining **CamillaDSP, ffmpeg, and ALSA**
- Real-time acoustic processing modeled on the **Musikverein** (Vienna's legendary concert hall)
- A metadata-driven database that lets you browse your library by genre, mood, and tempo
- A **Favorites** system for instantly recalling a track the moment you fall in love with it
- **Sonia Intelligence (SI)**, which lets you fine-tune the sound just by describing what you hear
- Radio, and streaming playback via Qobuz, SoundCloud, and YouTube Music
- Wireless playback through AirPlay and DLNA (UPnP) reception
- A **Now Playing Mirror** that shows the current cover art and track info in any phone or tablet browser on your network

Qji was built by its developer for daily personal use in a real home audio setup, one feature at a time, always prioritizing "a good listening experience" over raw efficiency.

## 2. System Requirements

### Required

| Item | Details |
|---|---|
| OS | Linux (tested on Ubuntu / Xubuntu) |
| Python | Python 3 with the `mutagen` package |
| Audio | ffmpeg, ALSA (`aplay`) |
| Image display | `feh` (cover art display), ImageMagick (`convert`, for overlaying track info) |
| Music library | A pre-analyzed metadata database (`~/music_mood_db.json`) |

This database is generated by a companion analysis script (e.g. `music_analyzer2.py`) that scans your music folders. Qji itself only reads this JSON database, so **you need to run the library analyzer first**.

### Optional (unlocks additional features)

| Feature | Requirement |
|---|---|
| Voice commands | `vosk` and `sounddevice` (Japanese speech model placed at `~/vosk-model-ja-0.22`) |
| Sonia Intelligence (SI) | The bundled `sonia_intelligence` module |
| AirPlay reception | `shairport-sync`, `avahi-daemon`, an ALSA loopback device (`snd-aloop`) |
| DLNA/UPnP reception | `gmediarender`, an ALSA loopback device (`snd-aloop`) |
| Qobuz / SoundCloud / YouTube Music playback | The corresponding modules (e.g. `qji_qobuzdsp.py`), `yt-dlp` |
| Now Playing Mirror | Any phone/tablet browser on the same Wi-Fi network |

You don't need everything set up at once — local library playback alone already gives you Qji's full acoustic engine.

## 3. Setup

1. Install the required system packages (ffmpeg, ALSA tools, feh, ImageMagick, etc.) via your distribution's package manager.
2. Install the Python dependencies (`mutagen` is required; `vosk`/`sounddevice` only if you want voice commands).
3. Place your music files in the folder(s) configured inside `qji.py` (e.g. `~/Music`, or wherever your external drives are mounted). Supported formats: `.wav / .flac / .wma / .aiff / .aif / .mp3 / .m4a / .aac / .ogg`.
4. Run the companion analysis script to generate `~/music_mood_db.json` — this becomes Qji's browsing database.
5. If you plan to use AirPlay or DLNA, load the `snd-aloop` kernel module:

   ```
   sudo modprobe snd-aloop
   ```

   To make this persistent, add `snd-aloop` to `/etc/modules`.

6. If you plan to use voice commands, extract the Japanese Vosk model into `~/vosk-model-ja-0.22`.

## 4. Starting Qji

### 4.1 From the desktop icon (double-click)

A desktop icon is created automatically during installation. Just double-click that icon to start Qji — this works from the very first launch, not only afterward.

### 4.2 From a terminal (alternative)

You can also run Qji from a terminal:

```
python3 qji.py
```

A splash screen (the "奏在" logo) appears for a few seconds, the database loads, and the main menu is displayed.

To start with voice recognition disabled, launch with the `--no-voice` flag.

## 5. Main Menu Overview

The main menu groups roughly into **track selection**, **audio/output settings**, and **external features**.

### Track selection

| Key | Function |
|---|---|
| `0` | Random playback from the whole library (up to 500 tracks) |
| `1` | Browse by tempo (BPM) |
| `2` | Browse by composer |
| `3` | Browse by performer |
| `4` | Browse by conductor |
| `5` | Browse by genre |
| `6` | Browse by mood |
| `7` | 🔍 Keyword search (title, composer, performer, etc.) |
| `8` | 🔷 Combine multiple filters (e.g. composer + genre) |
| `9` | 📊 Show mood statistics for the whole library |
| `J` | 🖼️ Browse and pick a track visually via cover-art thumbnails |
| `N` | 🆕 Browse recently-added tracks via cover-art thumbnails |

### Audio / output settings

| Key | Function |
|---|---|
| `A` | Audio presets (simple EQ — "vocal forward", "soloist forward", etc.) |
| `G` | Gain presets (see below — input-stage level control) |
| `L` | Toggle loudness normalization |
| `T` | Toggle tinnitus-reduction mode (gently tames high frequencies) |

| `V` | Toggle Musikverein room-effect (concert-hall reverb) |
| `F` | Switch soundfield/filter preset (11 options, see below) |
| `E` | Switch echo mode (classical-oriented / jazz-vocal-oriented) |
| `Z` | Toggle gapless playback (applies in folder-sequence mode) |
| `U` | Toggle upsampling and set the target sample rate |

### External features / management

| Key | Function |
|---|---|
| `R` | 📻 Play internet radio stations |
| `P` | 💾 Preset management — save/restore a whole audio settings profile under a name |
| `K` | ⭐ Favorites management |
| `M` | 📱 Toggle the Now Playing Mirror server (phone/tablet browser view) |
| `QB` | 🎵 Qobuz streaming playback |
| `S` | 🟠 SoundCloud streaming playback |
| `Y` | 🔴 YouTube Music streaming playback |
| `AP` | 📡 AirPlay receiver (receive from iPhone/Mac) |
| `DL` | 📻 UPnP/DLNA receiver (receive from BubbleUPnP, etc.) |
| `X` | 🔄 Re-detect the DSP output device (pick up a newly connected DAC) |
| `Q` | Quit |

## 6. In-Playback Key Controls

While a track is playing, press a key in the terminal to act on it immediately — no Enter key needed.

| Key | Action |
|---|---|
| `r` | Restart the current track from the beginning |
| `f` | Switch to sequential playback of the rest of the current folder |
| `n` | Next track |
| `b` | Previous track |
| `i` | Redisplay the cover art |
| `o` | ⭐ Add the currently playing track to Favorites |
| `w` | Toggle Air Particle Layer |
| `c` | Change the soundfield/filter preset on the fly |
| `g` | Cycle through gain presets |
| `+` / `=` | Raise output gain by +1 dB |
| `-` | Lower output gain by -1 dB |
| `s` | Save the entire current audio profile (per track/album) |
| `q` | Stop playback and return to the main menu |

**Additional keys, available only when Sonia Intelligence is loaded:**

| Key | Action |
|---|---|
| `z` | Type a free-form impression in Japanese (e.g. "bring the piano forward") |
| `h` | Select the acoustic hall/space |
| `p` | Select a saved SI profile |
| `x` | Select an SI acoustic preset by number |
| `a` | Manually register an acoustic preset for the current album |

An on-screen control guide is always shown below the track info during playback, so you never have to memorize these.

## 7. Soundfield Presets (Audio Filters)

Switch with `F` from the main menu, or `c` during playback. Eleven presets are available:

| Preset | Character |
|---|---|
| 🎻 Musikverein (Orchestra) | The default — models the reverb of Vienna's Musikverein, for orchestral works |
| 🎹 Piano | Tuned for solo piano and piano concertos |
| 🏠 Chamber | For chamber music, emphasizing natural intimacy |
| 🎙 Vocal | For lieder/vocal works, brings the voice forward |
| 🎷 Jazz | For jazz and pop |
| 🌿 Calm (安らぎ) | A still, calm soundscape — for relaxed listening |
| 🌊 Deep (深淵) | A deeper, more immersive soundfield — for focused night listening |
| 🌐 Spatial (3D空間音響) | Spatial processing designed for headphones |
| 📻 Radio (standard) | Standard processing tuned for radio streams |
| ⚪ Bypass (no processing) | No acoustic processing at all — a reference setting |
| 💿 Vinyl Emotion | Emulates the texture of an analog record |

If a preset ever feels wrong for what's playing, switch it instantly with `c`. The cover-art badge (top-left) always shows the active preset name, so a mismatch is obvious at a glance.

## 8. Gain Presets (Input-Stage Level)

Set with `G` from the main menu, or cycle through with `g` during playback.

| Preset | Value | Use case |
|---|---|---|
| Classical | 0 dB | Preserves delicate detail (e.g. solo violin) without distortion |
| General | -1.5 dB | Balanced, works across most genres |
| Jazz / Pop | -3.5 dB | Prevents distortion on higher-level recordings |
| Loud | -5 dB | Loud recordings, live material |

A jazz-linked auto-gain feature exists, but manually selecting with `g` disables the auto-link and keeps your choice.

## 9. Favorites

The moment a track catches your ear, press **`o`** to add it to your Favorites — instantly, with no prompt interrupting playback.

Each entry is automatically tagged with the track's genre and mood metadata. You can organize freely afterward from the `K` menu.

### Favorites menu (`K`)

| Option | Function |
|---|---|
| 1 | List all favorites (with tags, notes, and a missing-file check) |
| 2 | Filter and list by tag (choose by number, or type a name — case-insensitive) |
| 3 | Shuffle-play the entire Favorites list |
| 4 | Play only the tracks matching a chosen tag |
| 5 | Pick and play a single track from the list |
| 6 | Edit tags/notes on an existing entry |
| 7 | Remove an entry from Favorites |
| 8 | Detect and clean up entries whose file has moved or gone missing |

### A typical workflow

1. While listening, hit `o` the moment a track stands out (genre/mood tags are added automatically)
2. Later, when you have time, use `K` → `6` to add your own tags ("Schubert", "lieder", "miniature") and notes ("bought the score and used to sing this myself")
3. From then on, `K` → `4` and a tag pulls up every related track at once

As your Favorites grow, tag filtering plus numbered selection keeps the list manageable rather than overwhelming.

## 10. Sonia Intelligence (SI) — AI-Assisted Sound Feedback

Sonia Intelligence translates natural spoken/typed impressions (in Japanese) into acoustic adjustments. It's active only when the `sonia_intelligence` module loads successfully.

| Key | Function |
|---|---|
| `z` | Type a free-form impression — e.g. "bring the piano forward", "give the hall more depth", "the bass is too heavy", "bring out more shimmer in the strings" |
| `h` | Select the acoustic hall/space |
| `p` | Apply a previously saved SI profile |
| `x` | Select an SI acoustic preset by number |
| `a` | Manually link an acoustic preset to the current album |

Feedback entered via `z` is applied directly to the acoustic parameters, with a short explanation shown on screen — no need to think in dB values, just describe what you want.

## 11. Voice Commands

Qji supports fully offline speech recognition via Vosk — just speak into the microphone (requires `VOICE_RECOGNITION_AVAILABLE` and voice recognition enabled).

| Say (Japanese) | Meaning / Action |
|---|---|
| "フォルダ" / "フォルダー" (folder) | Switch to sequential folder playback |
| "テンポ" (tempo) | Switch to tempo browsing mode |
| "作曲家" (composer) | Switch to composer browsing mode |
| "演奏" / "オーケストラ" (performance / orchestra) | Switch to performer browsing mode |
| "指揮" (conducting) | Switch to conductor browsing mode |
| "ジャンル" (genre) | Switch to genre browsing mode |
| "ムード" (mood) | Switch to mood browsing mode |
| "次" (next) | Next track |
| "前" (previous) | Previous track |
| "もう一度" / "最初から" / "リプレイ" (again / from the start / replay) | Restart the current track |
| "終了" / "ストップ" / "停止" (end / stop) | Stop playback |
| "画像" / "ジャケット" (image / jacket) | Redisplay the cover art |

Since recognition runs fully offline, nothing is sent over the internet.

## 12. Radio

Press `R` to see a list of pre-registered internet radio stations (with country flags). Pick a number to start playback — the same acoustic filter chain used for local files applies here too.

The radio menu stays open after a stream ends, so you can browse through stations freely. Press `0` to return to the main menu.

## 13. Streaming Playback (Qobuz / SoundCloud / YouTube Music)

| Key | Service |
|---|---|
| `QB` | Qobuz (hi-res streaming) |
| `S` | SoundCloud |
| `Y` | YouTube Music |

All three inherit your currently active audio settings — gain preset, tinnitus reduction, Musikverein room effect, Air Particle Layer, echo mode, and output device — so streamed audio sounds like "Qji," not like a bare pass-through.

## 14. AirPlay / DLNA Receiver

### AirPlay (`AP`)

Send audio from an iPhone or Mac to Qji via AirPlay, and it plays through Qji's full acoustic filter chain. Requires `shairport-sync`, `avahi-daemon`, and an ALSA loopback device.

### DLNA/UPnP (`DL`)

Cast from a DLNA controller (e.g. BubbleUPnP) with Qji selected as the renderer. Requires `gmediarender` and an ALSA loopback device.

In both receiver modes, the following keys are available during playback:

| Key | Action |
|---|---|
| `c` | Change filter preset |
| `h` | Toggle Musikverein room effect |
| `a` | Toggle Air Particle Layer |
| `x` | Select an SI preset |
| `+` / `-` | Adjust volume |
| `q` | Stop |

If a required component is missing, Qji prints the exact install command needed.

## 15. Now Playing Mirror (Phone/Tablet Browser View)

Press `M` to start the mirror server, then open `http://(your PC's IP address):(port)/` from any phone or tablet browser on the same Wi-Fi network. You'll see the live cover art, track info, and the currently active soundfield preset.

The same preset info (filter name + gain preset name) is also shown as a badge directly on the cover-art display on the PC itself, so a mismatched setting is obvious the moment you look at the screen — not just on your phone.

## 16. Preset Management (Saving Settings)

Press `P` to save your entire current audio configuration — volume, output device, audio preset, gain preset, loudness normalization, tinnitus reduction, Musikverein room effect, gapless mode, upsampling, and filter preset — under a name.

| Option | Function |
|---|---|
| 1 | Save the current settings as a named preset |
| 2 | Load and apply a saved preset (by number or name) |
| 3 | List all saved presets |
| 4 | Delete a saved preset |
| 5 | Show the current settings |

Create one preset per listening scenario ("late-night solo listening", "party volume", etc.) and skip the manual tweaking next time.

## 17. Troubleshooting

| Symptom | Check |
|---|---|
| "Database file not found" at startup | Run the library analyzer (e.g. `music_analyzer2.py`) first to generate `~/music_mood_db.json` |
| Voice commands don't respond | Confirm `vosk`/`sounddevice` are installed, the model is unpacked at `~/vosk-model-ja-0.22`, and your USB microphone is recognized |
| AirPlay/DLNA won't work | Confirm `snd-aloop` is loaded (`sudo modprobe snd-aloop`) and `shairport-sync`/`gmediarender` are installed |
| SI keys (`z`/`h`/`p`/`x`/`a`) don't appear | The `sonia_intelligence` module likely failed to load — check the startup message |
| No track info overlaid on cover art | Confirm ImageMagick's `convert` command is installed |
| Output DAC not detected | Try `X` from the main menu (re-detect DSP output device) |

## 18. Glossary

| Term | Meaning |
|---|---|
| Qji (奏在, "Sōzai") | The project's Japanese name, evoking "music, present, here" |
| Musikverein | The famed Vienna concert hall whose reverb characteristics are modeled via ffmpeg filters |
| Air Particle Layer | A subtle pink-noise ambience layer meant to evoke the felt "presence of air" in a real hall |
| Soundfield / filter preset | A set of acoustic filter chains tuned per genre/scene (11 total) |
| Gain preset | An input-stage level preset used to prevent distortion |
| Sonia Intelligence (SI) | An AI-assisted system that adjusts the sound based on natural-language feedback |
| Now Playing Mirror | A browser-based mirror showing what's currently playing, viewable from any device on the network |
